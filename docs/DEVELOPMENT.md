# 开发与功能说明

正式版本 **1.0.0**，首版标签为 `v0.9`。后续默认递增补丁版本，未经用户允许不提升主版本号或次版本号。版本变化见 [CHANGELOG.md](../CHANGELOG.md)。

轻量、离线的 Android 原生 TXT 阅读应用，Android 8.0 及以上可安装。Java 17、原生 View、原生文字排版；无 WebView、网络权限、服务器或第三方运行时库。

LiNoRr 原名 LNReader。保留 Android 安装身份 com.lnreader.app 和签名以覆盖升级；项目目录与新安装包名称改为 LiNoRr。旧默认 Download/LNReader 在授权后迁移为 Download/LiNoRr，保留原始文件名与 JSON 记录；自定义位置不变，新旧目录都有内容时保留旧库而不覆盖目标。QA 模拟器继续使用原有 LNReader_QA 名称以沿用独立设备保护。

## 使用

从 GitHub Release 下载 `LiNoRr-1.0.0.apk`，可覆盖升级旧版。首次导入按系统提示授予文件读写权限：Android 11 及以上使用系统「所有文件访问权限」页面，Android 8～10 使用存储运行时授权。

- 顶栏用独立底色，依次是 LiNoRr、等距的日夜、设置、导入图标。点击下方书架图标／名称，或在书架区域向右短滑，打开分类抽屉；标题不再打开抽屉。
- 抽屉固定显示最近阅读、全部书籍，用横线与自建分类分隔，不显示无分类。最近阅读仅包含最近读过且未隐藏的 90 本。右滑打开、左滑关闭；底部提供新增书架和编辑书架，编辑时拖动项横向固定，其他项实时平滑让位，松手保存、取消恢复原顺序。点击铅笔进入行内改名，勾号保存、叉号或点击其他位置取消；改名时禁用拖动。垃圾桶删除分类，系统书架不可编辑。
- 书架名称右侧依次是排序、网格／列表和筛选面板开关。搜索和批量操作默认收起，数量始终显示；取消选择与数量同行，收起搜索同时退出选择。选中的整张书籍卡片加深，缩小角标，收紧书名与进度间距。
- 书架与章节搜索均在点击放大镜或键盘搜索／回车后执行，输入、粘贴、清空时不自动筛选。书架匹配书籍名称和 TXT 原文件名，不扫描正文。排序面板分为两组单选：最近阅读时间、文件名、文件大小、导入时间、书籍名称，以及升序／降序。各书架独立保存显示方式及排序；最近阅读例外，每次进入恢复最近阅读时间降序，临时排序不保存。最近阅读显示时钟图标，全部书籍显示书库图标，自建分类保留书架图标。
- 网格／列表每页最多显示 15 本；超过 15 本时，滑到当前页底部才显示上一页、下一页、页码输入和跳转。少于或等于 15 本不显示翻页控件。列表封面及文字一并缩小。
- 长按封面进入选择模式，可全选当前分类与搜索结果，跨页选中的项目一起处理。数量与搜索文字对齐，全选位于取消选择左侧。操作行依次为添加到书架、移出书架、移除所选；移出仅解除当前分类归属，全部书籍内可指定要移出的分类，不删除文件。最近阅读中移出使用 hiddenRecent 标记保存于 JSON，保留历史和进度，再次阅读重新出现。
- 每本书的管理按钮位于阅读进度右侧。管理面板顶部显示封面，导入／删除封面按钮紧随其后，导入居左；下方显示原文件名、文件大小、导入日期、页码、阅读百分比，可编辑书籍名称、分类和章节匹配。移除、删除、恢复默认等操作使用柔和红色。
- 手动封面使用应用内本地相册，可切换全部图片与各个图集；已有所有文件访问权限或全部照片权限时可浏览完整媒体库，缺少授权时直接申请照片权限。Android 14 及以上若只授予部分照片，界面会显示重新授权入口。缩略图异步加载并限制缓存；选中的原图压缩为最长边 720px 的 cover.jpg，备份到书籍目录。书籍管理中可删除当前封面并恢复生成封面，封面操作与章节匹配设置位于保存上方。
- 书架、阅读页共用日夜状态。日间恢复用户保存的背景色，夜间使用统一深色；设置、导入、书籍管理、目录、字体选择和确认窗口采用相同的浮层与明暗配色。
- 书架设置提供青绿、雾蓝、暖沙、藕粉、石墨、藤紫六种预设色块，保存在独立的 uiTheme 字段，不修改阅读背景或字体配置。备份路径可恢复默认 Download/LiNoRr，并迁移当前书库。

一本书可加入多个分类。数据库书籍记录中 shelfIds 是按加入顺序保存的分类 ID 数组，shelf 保留第一个 ID 以兼容旧记录；旧版单分类记录自动迁移。正文和封面只保留一份，存放于第一个分类目录，拖动书架顺序不会改变这个归属。书籍管理可增减分类，批量添加保留已有分类。删除分类仅移除对应归属，剩余分类继续保留；没有其他分类则放入无分类目录。全部书籍仍只统计一次。

## 导入、备份与删除

多选 TXT 或导入文件夹，可分别建书或按文件名自然排序（1、2、10）合成一本书。默认备份目录为手机共享存储的 **Download/LiNoRr**，常见完整路径是 `/storage/emulated/0/Download/LiNoRr`。

导入分类默认未分类，采用与书籍管理相同的折叠多选界面，分类名居左、勾选框居右。展开后可快速新建并选中书架，无需退出当前导入面板。

展开的分类、背景预设与自定义 RGB 使用统一描边，快速新建分类居中；编辑书架和选择文件夹提供柔和按钮底色。搜索旁的红叉清空输入并立即显示当前书架全部书籍，空输入时淡灰禁用。选中卡片背景在封面外围保留留白。批量导入和移除显示横向进度条、处理量与百分比，准备／扫描阶段采用不定进度。

```text
LiNoRr/
├── userdata.json        # 偏好、书架定义（小文件）
├── library.sqlite       # 书籍、阅读记录、书签、分页与操作日志
├── library.sqlite-wal   # 运行时可能存在；整体备份时一并复制
├── library.sqlite-shm   # 运行时可能存在
└── book/
    ├── 无分类/
    │   ├── 书籍1/
    │   │   ├── 书籍1.txt
    │   │   └── cover.jpg
    │   └── 书籍2/
    │       └── 书籍2.txt
    └── 分类1/
        └── 合集/
            ├── 第一个原名.txt
            ├── 第二个原名.txt
            └── cover.jpg
```

导入后一直读取应用备份，不再依赖源文件或源文件夹。外部原小说删除、移走或取消原 URI 授权，不影响备份中的小说；备份本身被手动删除则无法继续读取它。

- TXT 逐字节复制，保留原名、编码和换行。合书分别保留各个原文件，不插入分部标题。文件系统不支持的字符会替换，同名冲突加编号。
- 按有序分文件内容计算 SHA-256，文件名、书名和来源路径不参与去重。重复内容跳过，保留原书的进度、名称、分类和规则。相同文件名但内容不同属于新书，不覆盖现有正文。
- 没有「同步文件夹」功能，也不维护自动同步来源。再次选择文件或文件夹导入即可去重；文件夹选择器会记住上次导入位置。
- **移除书籍会删除该书的应用备份目录、封面、阅读历史、书签、分页记录和对应数据库记录，不再归档。** 外部源文件不删除。重新导入会从零开始阅读，但内容相同时仍得到相同的生成封面颜色。
- 升级时，0.9.5 中已经移出书架而保留在归档里的书籍及文件也会清理；不再提供恢复归档入口。尚未授权文件访问时，待授权后执行。
- 自动封面优先使用同目录同名图片，其次 cover、folder、封面或文件夹同名图片。支持 JPG/JPEG/PNG/WebP，也可从书籍管理手动导入。备份统一为最长边不超过 720px、JPEG 质量 82 的 cover.jpg，不改变原图。
- 没有图片时，按正文内容散列生成低饱和浅色封面。仅将 RGB 设为大于 150 仍可能产生刺眼颜色，因此同时限制 HSL 饱和度约 16%～24%、明度约 81%～87%，搭配深色文字；改名、换路径和删除后重新导入不改变同内容的颜色。

## 更换备份文件夹与迁移

书架设置可以选择本机或存储卡上的备份文件夹。已有书库会连同 library.sqlite 和 userdata.json 迁移过去，保留相对路径、分类、阅读记录、分页配置和书籍目录里的额外文件；迁移成功后清理原位置的应用备份。为了避免覆盖，不将当前书库合并进已有 library.sqlite 或 userdata.json 的其他书库，也不允许选择当前书库的父目录或子目录。

0.9.21 起，迁移在应用私有偏好中保存恢复记录。复制、发布文件和切换路径之间被结束进程，重启后会回滚本次迁移拥有的副本；切换成功后则继续清理旧副本，不回退正在使用的新书库。新位置暂时不可访问时保留旧副本与恢复记录，不创建空库。目标中无关文件不删除。此恢复记录仅供本机迁移使用，跨设备仍复制完整备份目录即可。

迁移到新手机时，先暂停导入并退出应用，再复制**整个**备份文件夹；不要只复制 userdata.json，也不要在写入中单独复制数据库。运行时存在的 SQLite 辅助文件一并复制：

1. 使用默认位置：复制到新手机 Download/LiNoRr，安装并授权后恢复。
2. 使用自定义位置：将整个备份文件夹复制到新手机，在空书库的设置中选择这个文件夹，即可打开已有书库。
3. 没有必要迁移应用私有目录。私有目录只保存元数据镜像、解码正文和索引缓存；清除缓存后可以从公共备份重建。

0.9.20 起，library.sqlite 保存书籍、分类归属、阅读位置、书签、原文件顺序、书籍名称、章节规则、内容标识和分页结果；userdata.json 保存分类定义、UI 与阅读偏好。原 TXT、cover.jpg、数据库和设置共同构成可迁移书库。旧版 userdata.json 自动流式迁移，不需要重新导入小说；首次升级大书库需要等待迁移完成。自选字体文件和系统字体因设备而异，换手机后可重新选择或导入。

旧版曾将多 TXT 合成一份正文；没有原文件时，升级只能迁移已有合并正文，无法自动还原原始分文件名。0.9.5 起新导入保留各个原文件。

## 阅读与目录

目录匹配新增默认开启的“数字编号”，支持 1.xxx、102.xxx、（10）xxx 等；“汉字数字编号”支持三十六、xxx、三十六.xxx、四十八 xxx 等，默认关闭，可在每本书的章节匹配设置勾选。标题保持原文，目录缓存版本更新，原有《蛊真人》默认目录仍为 2351 项。

- 默认字号 18、行距 1.4、段距 0.4；设置采用左侧项目、右侧数值，可直接输入。支持系统字体和 TTF/OTF 导入。
- 默认左右分页及平移动画，可选择无动画、滚动阅读。按左右分量识别单手短弧线，不限制横纵角度，忽略末端轻微回摆，明确回拖仍可取消；系统合并的历史触点也参与判断。平移随手指移动，左右两页同时呈现。支持章节边界，预览不提前写入进度。点击／音量翻页保留快速动画。支持中间显示／隐藏菜单、音量键翻页（可关闭）。
- 正文可长按选字，拖动选区手柄调整范围，并在浮动菜单点击复制；选字期间不触发翻页。滚动模式使用系统文字选择。
- 菜单隐藏时隐藏系统栏；顶部显示当前章节和返回键，底部显示全书页码、百分比、时间与电池。点击底部信息区或其下缘可打开菜单；正文中间 50% 打开菜单，左右各 25% 点击翻页。菜单展开时，正文点击仅收起菜单，拖动、滚动与音量键不翻页；章节按钮和进度条仍可操作。顶部书签入口支持添加、去重、跳转、删除。
- 日间背景保留纸白、青竹、米黄、暖灰、雾蓝、浅杏、淡粉及自定义 RGB；夜间不作为预设颜色出现。修改日间背景时切换到日间实时预览，之后夜间切换不会丢失该背景。
- 无缩进正文在显示时补入两个实际的全角中文空格（U+3000），已有缩进保持；删除显示中的空白行。原始 TXT 不变，额外空格通过偏移映射关联到原文，阅读位置与书签不受插入字符影响。
- 目录保留分级折叠、搜索、当前路径展开与当前章背景高亮。点选后目录保持打开，点击返回阅读或系统返回关闭。

**默认章节规则收回到旧版范围**：第 N 卷／部／篇／章／节／目／话／回／集，Chapter／Part／Book／Volume，以及原有序言、楔子、尾声等。幕、场、折、EP.、Episode、Section、Act、Scene 默认关闭。

目录右上角设置图标和书籍管理的「章节匹配设置」共用同一本书的规则：

- 勾选或取消对应结构名称，支持只匹配章、不匹配节等组合。
- 添加自定义标题名称，并选择卷级、篇级、章级、节级或目级。例如「季」匹配「第1季」，「Season」匹配「Season 1」，「EP.」匹配「EP.1」。名称按字面匹配，不作为可执行正则表达式。
- 自定义名称可删除，可恢复默认匹配；保存后重建该书目录并保持原文阅读位置。
- 不生成「正文」「前言」「续」目录，不改写原有标题；没有匹配结果时显示未识别到章节。长文本的内部渲染窗口不进入目录。

## 分页缓存与性能

每本书将累计页数数组与字体、字号、行距、段距、翻页方式、屏幕尺寸、密度及字体文件标识一起保存在备份目录的数据库中。再次打开时，排版和内容边界一致便直接复用，不重复计算全书页数；清空应用缓存后仍可使用该记录。更改字体、间距、屏幕方向或实际章节边界会使对应结果失效。仅切换日夜、修改背景色或调整目录层级，不会使未变化的版面重新分页。

正文、目录和分页各自后台处理，首次无结果时先进入阅读并后台计算页数。0.9.6 调整了默认目录和缩进，升级后的旧书可能需要重新计算一次；后续复用新结果。尚无有效页数时显示「—/— 页」，不显示章节页码。

独立 Android 15 模拟器验证了约 23 MB《蛊真人》的正文及目录加载（默认 2,351 个原文标题）、700 本书架每页 15 条、内容去重、备份删除／迁移、原文件删除后阅读、缓存清除后的分页复用，以及更改字号后的缓存失效。仍需实体手机验证，不将模拟器测量视为所有手机的速度承诺。

## 隐私模式

单击 LiNoRr 标题查看图标、版本及作者，双击切换隐私模式。普通模式不显示隐私入口，隐藏隐私书籍、搜索结果及仅包含隐私书籍的分类；隐私模式使用绯红／酒红主题，标题旁增加眼睛退出按钮与「隐私书籍」系统书架。

隐私模式内可在书籍管理、批量操作中添加／移出隐私，也可在导入时勾选。编辑书架时，用户分类旁的眼睛按钮可统一设置该分类内的书籍。隐私标记属于书籍，多分类中保持一致，随书籍数据库记录保存；模式状态不保存，冷启动回普通模式，后台切回保持当前模式。

## 大书库与后台任务

书库元数据使用 Android 内置 SQLite，按每页 15 本加载，后台处理筛选与排序；内存中的书籍记录最多缓存 160 条。翻页只更新当前书籍，不重写 10 万本元数据。目录、分页和封面任务的等待队列有界；解码／索引缓存按 128MB、64 本回收，当前阅读的一本允许保留。

大量导入建议选择文件夹，避免系统文件选择器自身多选结果过大的限制。一次只运行一个导入任务，分组提交，优先保持阅读可用；进度面板可「继续阅读」或「暂停导入」。应用进程被系统结束后不保证继续后台运行，已完成书籍和准备提交的操作会恢复；重新选择原来源导入会跳过重复内容。不会为了提速创建数万线程或同时解码数万本小说。

文件清单、单本正文和目录数量按设备内存设置安全上限，超限会提示分批或缩小章节匹配范围，避免持续分配直到崩溃。用户移除、改分类和改备份路径期间暂停其他书籍管理操作；导入期间仍可浏览、搜索和阅读已有书籍。

导入使用固定缓冲区复制、计算内容标识和校验编码，不同时持有整本原始字节与解码字符串；合书按累计字符预算校验。冷打开正文逐文件追加，缓存写入也使用流式编码。清理空分类只探测首个目录项。相册每页最多保留 200 张图片元数据，图集计数在后台流式聚合到临时 SQLite，关闭面板取消查询并清理索引。

规模回归使用独立 Android 15 模拟器：10 万条旧记录（超过 32MB 的 JSON）流式迁移，数据库分页／隐私筛选，以及 3 万个内容各不相同的小 TXT 实际备份、去重续传、导入时阅读和中断恢复。此测试验证数量与恢复逻辑，不代表 3 万本长篇小说的空间或耗时；实际速度取决于总字节数、存储设备及系统文件提供器。

## 构建与验证

JDK 17、Android SDK 35；在 Android Studio 打开本目录，或设置 JAVA_HOME、ANDROID_HOME：

```sh
./gradlew assembleDebug assembleDebugAndroidTest lintDebug
npm run test:native-parser
# 独立 LNReader_QA 模拟器中顺序执行，不能与导入／其他 UI 测试并行：
npm run test:storage
npm run test:android
npm run test:recovery
npm run test:gallery
npm run test:scale
# 规模测试超时或进程中断后，从已有的 QA 检查点续跑：
npm run test:scale -- --resume
```

- test:native-parser：目录、编码、缩进与偏移、浅色封面、文件备份、自然排序、参考小说及 1,000 组分页布局；可用 LINORR_GU_FIXTURE 指定《蛊真人》测试文件。另在 64MB JVM 堆中保留模拟阅读内存，验证大文件流式校验与超限拒绝；不代表所有手机都不会耗尽内存。
- test:storage：原始编码和多 TXT 备份、去重、分类迁移、书签与分页、清缓存恢复、合书长文件清单、自然排序、跨页全选、隐私、最近 90 本、物理删除、弹窗释放、日志分块和备份路径迁移；含移动恢复保留新进度、日志原子清理失败回滚、退出隐私刷新分类计数的回归。
- test:android：原生阅读手势、短弧线／回拖、跨章节、选字、音量／滚动、进度条拖动与实时预览、书签状态。
- test:recovery：在复制、部分发布、全部发布、回滚删除、路径切换、旧副本清理失败、新库暂时不可访问七种检查点结束进程，再由新进程验证恢复与原文完整性。
- test:gallery：实际创建 205 张测试图片，验证图集磁盘索引、200／5 张分页、返回上一页及关闭清理。
- test:scale：10 万条目录记录加 3 万个不同 TXT 的长时间规模回归。仅测试 APK 含用于生成测试 TXT 的 Provider，正式应用不包含。
- tests/android.mjs、polish-android.mjs、interaction-android.mjs、privacy-android.mjs、media-android.mjs 保留为旧存储或旧相册实现的历史 UI 脚本；不作为当前版本的通过依据，新回归由上述命令执行。

应用产物为 app/build/outputs/apk/debug/app-debug.apk。Android 构建无需 Node/npm，后者只用于测试脚本。Lint 无错误，保留所有文件访问权限相关的发布政策提示。

正式包使用 `./gradlew assembleRelease lintRelease` 构建，再在仓库外使用私有密钥签名；不要提交密钥。已发布的 1.0.0 沿用测试版的签名以支持覆盖升级，包内调试标志关闭。可通过 `LINORR_APK=artifacts/LiNoRr-1.0.0.apk npm run test:storage` 等命令，对签名后的正式 APK 执行同一组模拟器回归。

图标源图保存在 design/，不进入 APK。安装 Pillow 后可运行 scripts/build-icons.py 重新生成资源。

设备测试仅允许名称以 LNReader_QA 开头的独立模拟器，会清空该模拟器的 LiNoRr 数据，不操作实体手机。截图和日志位于 artifacts/。

仓库保留独立的 0.9 浏览器历史原型（npm run preview、npm test、npm run test:ui），使用 IndexedDB，不打入 APK。
