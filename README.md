# LNReader

当前版本 **0.9.13**，首版标签为 `v0.9`。只递增补丁版本，未经用户允许不提升主版本号或次版本号。版本变化见 [CHANGELOG.md](CHANGELOG.md)。

轻量、离线的 Android 原生 TXT 阅读应用，Android 8.0 及以上可安装。Java 17、原生 View、原生文字排版；无 WebView、网络权限、服务器或第三方运行时库。

## 使用

安装 `artifacts/LNReader-0.9.13-debug.apk`，可覆盖升级旧版；`artifacts/LNReader-debug.apk` 是同一份最新测试包。首次导入按系统提示授予文件读写权限：Android 11 及以上使用系统「所有文件访问权限」页面，Android 8～10 使用存储运行时授权。

- 顶栏用独立底色，依次是 LNReader、等距的日夜、设置、导入图标。点击下方书架图标／名称，或在书架区域向右短滑，打开分类抽屉；标题不再打开抽屉。
- 抽屉固定显示最近阅读、全部书籍，用横线与自建分类分隔，不显示无分类。最近阅读仅包含最近读过的 90 本。右滑打开、左滑关闭；底部提供新增书架和编辑书架，编辑时拖动项横向固定，其他项实时平滑让位，松手保存、取消恢复原顺序；也可用铅笔改名、用垃圾桶删除。系统书架不可编辑。
- 书架名称右侧依次是排序、网格／列表和筛选面板开关。搜索和批量操作默认收起，数量始终显示；取消选择与数量同行，收起搜索同时退出选择。选中的整张书籍卡片加深，缩小角标，收紧书名与进度间距。
- 书架与章节搜索均在点击放大镜或键盘搜索／回车后执行，输入、粘贴、清空时不自动筛选。书架匹配书籍名称和 TXT 原文件名，不扫描正文。排序面板分为两组单选：最近阅读时间、文件名、文件大小、导入时间、书籍名称，以及升序／降序。各书架独立保存显示方式及排序；最近阅读例外，每次进入恢复最近阅读时间降序，临时排序不保存。最近阅读显示时钟图标，全部书籍显示书库图标，自建分类保留书架图标。
- 网格／列表每页最多显示 15 本；超过 15 本时，滑到当前页底部才显示上一页、下一页、页码输入和跳转。少于或等于 15 本不显示翻页控件。列表封面及文字一并缩小。
- 长按封面进入选择模式，可全选当前分类与搜索结果，跨页选中的项目一起处理。支持批量添加到分类、移除。
- 每本书的管理按钮位于阅读进度右侧。管理面板顶部显示封面，下方显示原文件名、文件大小、导入日期、页码、阅读百分比，可编辑书籍名称、分类、封面和章节匹配。移除、删除、恢复默认等操作使用柔和红色。
- 手动封面使用应用内本地相册，可切换全部图片与各个图集；已有所有文件访问权限或全部照片权限时可浏览完整媒体库，缺少授权时直接申请照片权限。Android 14 及以上若只授予部分照片，界面会显示重新授权入口。缩略图异步加载并限制缓存；选中的原图压缩为最长边 720px 的 cover.jpg，备份到书籍目录。书籍管理中可删除当前封面并恢复生成封面，封面操作与章节匹配设置位于保存上方。
- 书架、阅读页共用日夜状态。日间恢复用户保存的背景色，夜间使用统一深色；设置、导入、书籍管理、目录、字体选择和确认窗口采用相同的浮层与明暗配色。
- 书架设置提供青绿、雾蓝、暖沙、藕粉、石墨、藤紫六种预设色块，保存在独立的 uiTheme 字段，不修改阅读背景或字体配置。备份路径可恢复默认 Download/LNReader，并迁移当前书库。

一本书可加入多个分类。userdata.json 中 shelfIds 是按加入顺序保存的分类 ID 数组，shelf 保留第一个 ID 以兼容旧记录；旧版单分类记录自动迁移。正文和封面只保留一份，存放于第一个分类目录，拖动书架顺序不会改变这个归属。书籍管理可增减分类，批量添加保留已有分类。删除分类仅移除对应归属，剩余分类继续保留；没有其他分类则放入无分类目录。全部书籍仍只统计一次。

## 导入、备份与删除

多选 TXT 或导入文件夹，可分别建书或按文件名自然排序（1、2、10）合成一本书。默认备份目录为手机共享存储的 **Download/LNReader**，常见完整路径是 `/storage/emulated/0/Download/LNReader`。

```text
LNReader/
├── userdata.json
└── book/
    ├── 无分类/
    │   ├── 书籍1/
    │   │   ├── 书籍1.txt
    │   │   └── cover.jpg
    │   └── 书籍2/
    │       └── 书籍2.txt
    └── 分类1/
        └── 合集/
            ├── 第一个原名.txt
            ├── 第二个原名.txt
            └── cover.jpg
```

导入后一直读取应用备份，不再依赖源文件或源文件夹。外部原小说删除、移走或取消原 URI 授权，不影响备份中的小说；备份本身被手动删除则无法继续读取它。

- TXT 逐字节复制，保留原名、编码和换行。合书分别保留各个原文件，不插入分部标题。文件系统不支持的字符会替换，同名冲突加编号。
- 按有序分文件内容计算 SHA-256，文件名、书名和来源路径不参与去重。重复内容跳过，保留原书的进度、名称、分类和规则。相同文件名但内容不同属于新书，不覆盖现有正文。
- 没有「同步文件夹」功能，也不维护自动同步来源。再次选择文件或文件夹导入即可去重；文件夹选择器会记住上次导入位置。
- **移除书籍会删除该书的应用备份目录、封面、阅读历史、书签、分页记录和对应 JSON 条目，不再归档。** 外部源文件不删除。重新导入会从零开始阅读，但内容相同时仍得到相同的生成封面颜色。
- 升级时，0.9.5 中已经移出书架而保留在归档里的书籍及文件也会清理；不再提供恢复归档入口。尚未授权文件访问时，待授权后执行。
- 自动封面优先使用同目录同名图片，其次 cover、folder、封面或文件夹同名图片。支持 JPG/JPEG/PNG/WebP，也可从书籍管理手动导入。备份统一为最长边不超过 720px、JPEG 质量 82 的 cover.jpg，不改变原图。
- 没有图片时，按正文内容散列生成低饱和浅色封面。仅将 RGB 设为大于 150 仍可能产生刺眼颜色，因此同时限制 HSL 饱和度约 16%～24%、明度约 81%～87%，搭配深色文字；改名、换路径和删除后重新导入不改变同内容的颜色。

## 更换备份文件夹与迁移

书架设置可以选择本机或存储卡上的备份文件夹。已有书库会连同 userdata.json 迁移过去，保留相对路径、分类、阅读记录、分页配置和书籍目录里的额外文件；迁移成功后清理原位置的应用备份。为了避免覆盖，不将当前书库合并进已有 userdata.json 的其他书库，也不允许选择当前书库的父目录或子目录。

迁移到新手机时，先退出阅读，再复制整个备份文件夹：

1. 使用默认位置：复制到新手机 Download/LNReader，安装并授权后恢复。
2. 使用自定义位置：将整个备份文件夹复制到新手机，在空书库的设置中选择这个文件夹，即可打开已有 userdata.json。
3. 没有必要迁移应用私有目录。私有目录只保存元数据镜像、解码正文和索引缓存；清除缓存后可以从公共备份重建。

userdata.json 保存分类、阅读位置、书签、原文件顺序、书籍名称、章节规则、日夜与阅读偏好、内容标识，以及上次分页结果和对应排版配置。原 TXT 与 cover.jpg 一同构成可迁移书库。自选字体文件和系统字体因设备而异，换手机后可重新选择或导入。

旧版曾将多 TXT 合成一份正文；没有原文件时，升级只能迁移已有合并正文，无法自动还原原始分文件名。0.9.5 起新导入保留各个原文件。

## 阅读与目录

- 默认字号 18、行距 1.4、段距 0.4；设置采用左侧项目、右侧数值，可直接输入。支持系统字体和 TTF/OTF 导入。
- 默认左右分页及平移动画，可选择无动画、滚动阅读。按左右分量识别单手短弧线，不限制横纵角度，忽略末端轻微回摆，明确回拖仍可取消；系统合并的历史触点也参与判断。平移随手指移动，左右两页同时呈现。支持章节边界，预览不提前写入进度。点击／音量翻页保留快速动画。支持中间显示／隐藏菜单、音量键翻页（可关闭）。
- 正文可长按选字，拖动选区手柄调整范围，并在浮动菜单点击复制；选字期间不触发翻页。滚动模式使用系统文字选择。
- 菜单隐藏时隐藏系统栏；顶部显示当前章节和返回键，底部显示全书页码、百分比、时间与电池。进度条两侧有上一章、下一章；顶部书签入口支持添加、去重、跳转、删除。
- 日间背景保留纸白、青竹、米黄、暖灰、雾蓝、浅杏、淡粉及自定义 RGB；夜间不作为预设颜色出现。修改日间背景时切换到日间实时预览，之后夜间切换不会丢失该背景。
- 无缩进正文在显示时补入两个实际的全角中文空格（U+3000），已有缩进保持；删除显示中的空白行。原始 TXT 不变，额外空格通过偏移映射关联到原文，阅读位置与书签不受插入字符影响。
- 目录保留分级折叠、搜索、当前路径展开与当前章背景高亮。点选后目录保持打开，点击返回阅读或系统返回关闭。

**默认章节规则收回到旧版范围**：第 N 卷／部／篇／章／节／目／话／回／集，Chapter／Part／Book／Volume，以及原有序言、楔子、尾声等。幕、场、折、EP.、Episode、Section、Act、Scene 默认关闭。

目录右上角设置图标和书籍管理的「章节匹配设置」共用同一本书的规则：

- 勾选或取消对应结构名称，支持只匹配章、不匹配节等组合。
- 添加自定义标题名称，并选择卷级、篇级、章级、节级或目级。例如「季」匹配「第1季」，「Season」匹配「Season 1」，「EP.」匹配「EP.1」。名称按字面匹配，不作为可执行正则表达式。
- 自定义名称可删除，可恢复默认匹配；保存后重建该书目录并保持原文阅读位置。
- 不生成「正文」「前言」「续」目录，不改写原有标题；没有匹配结果时显示未识别到章节。长文本的内部渲染窗口不进入目录。

## 分页缓存与性能

每本书将累计页数数组与字体、字号、行距、段距、翻页方式、屏幕尺寸、密度及字体文件标识一起保存到 userdata.json。再次打开时，排版和内容边界一致便直接复用，不重复计算全书页数；清空应用缓存后仍可使用该记录。更改字体、间距、屏幕方向或实际章节边界会使对应结果失效。仅切换日夜、修改背景色或调整目录层级，不会使未变化的版面重新分页。

正文、目录和分页各自后台处理，首次无结果时先进入阅读并后台计算页数。0.9.6 调整了默认目录和缩进，升级后的旧书可能需要重新计算一次；后续复用新结果。尚无有效页数时显示「—/— 页」，不显示章节页码。

独立 Android 15 模拟器验证了约 23 MB《蛊真人》的正文及目录加载（默认 2,351 个原文标题）、700 本书架每页 15 条、内容去重、备份删除／迁移、原文件删除后阅读、缓存清除后的分页复用，以及更改字号后的缓存失效。仍需实体手机验证，不将模拟器测量视为所有手机的速度承诺。

## 构建与验证

JDK 17、Android SDK 35；在 Android Studio 打开本目录，或设置 JAVA_HOME、ANDROID_HOME：

```sh
./gradlew assembleDebug assembleDebugAndroidTest lintDebug
npm run test:native-parser
# 独立 LNReader_QA 模拟器中，顺序执行：
npm run test:android
npm run test:storage
npm run test:polish
```

应用产物为 app/build/outputs/apk/debug/app-debug.apk。Android 构建无需 Node/npm，后者只用于测试脚本。Lint 无错误，保留 MANAGE_EXTERNAL_STORAGE 对应的 ScopedStorage 发布政策提醒；若以后上架 Google Play，需要单独满足该权限审核要求。

- test:native-parser：默认／按书自定义目录、无假标题、两全角空格与偏移映射、浅色封面色域、文件备份、编码、自然排序、真实参考小说、1,000 组分页边界。
- test:android：连续／短滑／音量翻页，滚动进度，目录折叠与高亮，书签、字号、RGB、系统栏、默认值迁移和升级保留数据。
- test:storage：旧版归档清理，原始编码／分文件备份，按内容去重与封面稳定性，真实删除，分页结果持久化与字体失效，目录个性化，备份迁移，700 书籍分页，抽屉两种入口，统一日夜，实际系统文件选择器、原文件名搜索、批量操作、清除私有数据后的恢复。
- test:polish：在 test:storage 后执行，检查半页停留／回拖取消／短滑提交／章节边界、数量与选择状态、排序单选、双向抽屉、拖动排序与分类增删改、多分类单份备份、独立 UI 色系、恢复默认目录与相册入口。UI 测试串行执行。
- test:media：在专用 API 35 模拟器验证所有文件访问／完整照片／部分照片权限、多个本地相册、缩略图、按相册选图、压缩备份与删除封面，以及书籍管理操作顺序和排序留白；测试图片与目录自动清理。与其他 UI 测试串行执行。

图标源图保存在 design/，不进入 APK。安装 Pillow 后可运行 scripts/build-icons.py 重新生成 WebP 密度与自适应资源；无 PSD 打包。

设备测试仅允许名称以 LNReader_QA 开头的独立模拟器，会清空其 LNReader 数据，不操作实体手机。截图位于 artifacts/。

仓库仍保留独立的 0.9 浏览器历史原型（npm run preview、npm test、npm run test:ui），使用 IndexedDB，不打入 APK，其数据和界面与正式 Android 版独立。
