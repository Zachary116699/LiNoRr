# LNReader

当前版本 **0.9.5**，首版标签为 `v0.9`。后续只递增补丁版本，未经用户允许不提升主版本号或次版本号。版本变化见 [CHANGELOG.md](CHANGELOG.md)。

轻量、离线的 Android 原生 TXT 阅读应用，Android 8.0 及以上可安装。Java 17、Android 原生 View、原生文字排版；无 WebView、网络权限、服务器或第三方运行时库。

## 使用

1. 安装 `artifacts/LNReader-0.9.5-debug.apk`；`LNReader-debug.apk` 是同一份最新测试包，可覆盖升级旧版。
2. 点击「导入书籍」，按系统提示授予文件读写权限。Android 11 及以上使用系统「所有文件访问权限」页面；Android 8～10 使用存储运行时授权。
3. 多选 TXT 或导入文件夹，选择分别建书或合并成一本书。合并按文件名自然排序（1、2、10），每份原始文件分别备份，不添加「第几部」等正文标题。
4. 书架顶部依次是日夜切换、设置、导入。默认分类为「最近阅读」「全部」，可创建、重命名、删除自己的分类；搜索仅匹配书名。
5. 点击封面阅读，长按封面进入选择模式。「全选当前筛选」只选当前分类和搜索结果；可批量添加到分类、移出书架。在设置的「从备份批量添加书籍」中恢复已移除项。
6. 每本书的管理按钮在阅读百分比右侧，可改名、分类、导入封面。封面与文字封面统一尺寸，提供网格和列表显示。

## 备份与迁移

固定备份根目录为手机共享存储的 **`Download/LNReader`**（常见完整路径 `/storage/emulated/0/Download/LNReader`）：

```text
Download/LNReader/
├── userdata.json
└── book/
    ├── 无分类/
    │   ├── 书籍1/
    │   │   ├── 书籍1.txt
    │   │   └── cover.jpg
    │   └── 书籍2/
    │       └── 书籍2.txt
    └── 分类1/
        └── 合集/
            ├── 第一个原名.txt
            ├── 第二个原名.txt
            └── cover.jpg
```

- `userdata.json` 保存书架分类、阅读位置、阅读时间、书签、阅读偏好、文件顺序和相对路径。正文、封面和该文件一起构成可迁移书库。
- 新导入的 TXT 按原始字节复制，保留文件名、编码和换行；不修改或删除外部源文件。多文件合书仍保留各个 TXT。文件系统不支持的字符会替换，同名冲突加编号。
- 自动封面优先使用同目录同名图片，其次 `cover`、`folder`、`封面` 或文件夹同名图片。手动导入支持 JPG/JPEG/PNG/WebP。备份统一为最长边不超过 720px、JPEG 质量 82 的 `cover.jpg`，不改变原图。
- 修改书名或分类会整理备份目录。移出书架保留备份文件及阅读记录；恢复入口会重新加入原书，无须重复导入。同步默认跳过这些已移除项。
- 迁移时先退出阅读，再复制整个 `LNReader` 文件夹到新手机的 `Download` 下，安装应用并授权。应用恢复 `userdata.json` 后读取相对路径；外部原小说、系统自动备份均不是必需条件。
- 应用私有目录保留元数据镜像用于写入恢复；`cache/books` 只保存可重新生成的解码正文、目录索引和分页缓存。清除缓存不影响备份。旧版私有正文在升级迁移时复制到上述目录，保留阅读位置与书签。
- **旧版合并书籍的限制：**旧版已把多份 TXT 写成一份正文，若原文件不可用，升级只能备份这份现有正文，无法还原原始分文件与原名。0.9.5 新导入不会发生此问题。
- 自选字体文件与系统字体因设备而异，换手机后可重新选择或导入。手选同步文件夹的系统授权也需要在新手机重新设置。

## 文件夹同步

备份目录始终固定为 `Download/LNReader`。设置中可单独指定「同步来源」，用于从其他文件夹读取小说；点击首页「同步文件夹」才执行，导入结果仍备份到固定目录。

默认同步扫描 `book/分类/书名/` 结构，一本书目录里的 TXT 作为一本书，已有分文件保持记录的顺序，新文件按自然排序追加；识别新增分类和书籍。也扫描 `LNReader` 根目录及 `book` 以外子目录的散放 TXT，分别导入到「无分类」。不会删除散放源文件，重复同步不会重复创建同一路径的书籍。

手选同步来源通过 Android 文件夹选择器授权，递归扫描并分别建书。导入文件夹不会自动改掉同步来源。同步保留同一书籍的进度、书签和重命名；不会因源文件消失而自动删除书架项目。外部文本大幅修改后，按原字符位置记录的进度可能偏移；手动更换路径或文件名也可能被视为新书。

## 阅读

- 默认左右分页和平移动画（140ms），可选无动画或滚动模式；支持短滑动、快速连续翻页、点击左右翻页、中间显示／隐藏菜单。音量下键下一页、音量上键上一页，可关闭。
- 默认字号 18、行距 1.4、段距 0.4；设置采用左侧项目、右侧数值，支持直接输入。可选择系统字体和导入 TTF/OTF。
- 菜单隐藏时同时隐藏系统栏；顶部显示当前章节及返回键，底部显示全书页码、百分比、时间、电池图标。全书分页在后台计算并缓存，未完成显示「—/— 页」，不显示章节页码。
- 进度条两侧提供上一章、下一章。顶部书签图标打开列表，可添加、去重、删除、跳转。
- 目录按层级折叠，默认只展开当前章节的上级路径；当前章深色背景、加粗。点选章节保持目录打开，点击「返回阅读」或系统返回关闭。支持搜索、全部展开／收起。
- 识别中文卷、部、篇、章、节、目、话、回、集、幕、场、折及常用繁体形式；英文 `Volume/Vol`、`Book`、`Part`、`Chapter/Chap/Ch`、`Episode/EP`、`Section/Sec`、`Act`、`Scene`，支持 `EP.01`、阿拉伯数字与英文罗马数字；识别原有序言、楔子、尾声、番外、Prologue/Epilogue 等标题。
- 目录只包含原文中匹配的标题，保留原有名称；未识别到章节时不造目录，不添加「正文」「前言」「续」。长文本内部按窗口渲染，这些窗口不进入目录、不插入文字。
- 无首行缩进的正文显示为两字缩进，已有缩进保持；去掉显示中的空白行，段距由设置控制。原始 TXT 和源字符位置不变，分页与滚动共用位置映射。
- 八种背景预设有选中标识；选择「自定义」才展开 RGB 数值、滑条和实时预览。

## 性能与限制

书架改用 `GridView` 复用屏幕内单元格，封面异步缩略解码并缓存；切换「全部」不创建数百个书籍视图。解码正文、目录解析、全书分页、导入和保存分别在后台处理。打开书籍优先复用内存文档与磁盘目录索引，布局变化后只重建对应分页缓存。

0.9.5 在独立 Android 15 模拟器实测约 23 MB《蛊真人》：多次检查中首次生成正文与目录缓存约 298～326ms，磁盘缓存加载约 37～112ms，内存复用约 0～2ms，识别 2,399 个原文标题。700 本书的书架视图构建约 4～9ms，仅创建屏幕附近单元格。这些是本次模拟器测量，正文加载时间不包含首次全书分页，书架构建时间不包含后续屏幕绘制，实体手机表现会不同。

单本原文件合计上限 80MB，并按设备堆内存降低；封面输入上限 32MB，字体 40MB。单选 TXT 的系统选择器不会同时授予相邻图片的 URI 权限，请一并选择图片或导入文件夹；也可稍后在书籍管理中导入封面。

## 构建与验证

JDK 17、Android SDK 35；在 Android Studio 打开本目录，或设置 `JAVA_HOME`、`ANDROID_HOME` 后执行：

```sh
./gradlew assembleDebug assembleDebugAndroidTest lintDebug
npm run test:native-parser
# 启动独立 LNReader_QA 模拟器后，顺序执行：
npm run test:android
npm run test:storage
```

应用产物为 `app/build/outputs/apk/debug/app-debug.apk`。Android 构建无需 Node/npm，后者仅用于测试脚本。Lint 无错误；保留一条 `ScopedStorage` 提醒，对应本版为固定公共目录读写而引入的 `MANAGE_EXTERNAL_STORAGE` 权限；若以后上架 Google Play，需单独满足该权限的发布审核政策。

- `test:native-parser`：多种章节形式、无目录文本、不生成续标题、显示到原文的偏移映射、备份字节一致性、路径校验、编码、自然排序、真实小说、1,000 组分页边界。
- `test:android`：原生左右／音量／短滑翻页、连续动画、滚动与位置恢复、目录折叠与选中、书签、设置数值、RGB、系统栏、默认值迁移、覆盖安装保留数据。
- `test:storage`：旧版私有书库迁移、多 TXT 原名与原始编码备份、压缩封面、删除源文件及缓存后阅读、清除私有数据后从公共目录恢复、700 书籍回收视图、等尺寸封面、日夜模式、筛选全选、批量分类／移除／恢复、权限页面恢复、默认目录与手选来源的同步去重及更新。

设备测试仅允许名称以 `LNReader_QA` 开头的独立模拟器，会清空该模拟器内的 LNReader 数据；不操作实体手机。截图输出到 `artifacts/`，目前尚未做实体手机验证。

仓库还保留单独的 0.9 浏览器历史原型（`npm run preview`，`npm test`，`npm run test:ui`）；它使用 IndexedDB，不打入 APK，数据与正式 Android 版独立，也不代表当前界面。
